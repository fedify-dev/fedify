 -  Added the `deno-kv-store-deprecated` and
    `deno-kv-message-queue-deprecated` rules, which warn when code imports or
    uses `DenoKvStore` or `DenoKvMessageQueue` from the deprecated
    `@fedify/denokv` package.  Named imports, aliases, type-only imports,
    re-exports, and namespace imports are covered.  Deno Lint reports
    plugin rules as errors, so projects generated by `fedify init` exclude the
    selected rule while keeping the deprecated option usable.
    [[#1335], [#1340]]
