    arrays, preventing a clone's remote lookups from changing its source and
    preserving arrays supplied by callers.

    language subtags, such as `zh-YUE`, in language-tagged strings and
    `fedify:langTag` values.  Code generated by this version requires
    a release of *@fedify/vocab-runtime* that includes this fix.
    [[#1229], [#1231]]
