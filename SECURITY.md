Security policy
===============

Supported versions
------------------

We support the latest two minor versions of the library. For example, if the
latest version is 2.4.0, we support 2.4.x and 2.3.x.

This is our minimum support commitment: depending on the severity of the
vulnerability, the maintainers may also release security updates for older
minor or major versions.


Reporting a vulnerability
-------------------------

If you think you have found a security issue, please *do not* open a public
issue.  Instead, please open a private vulnerability report by
[creating a new draft security advisory][1].

We will review your report and respond within 48 hours.

[1]: https://github.com/fedify-dev/fedify/security/advisories/new


Security update embargo
-----------------------

To minimize harm, we typically wait 48–72 hours after releasing a security
update before publishing the security advisory details and the official
announcement. This embargo gives users time to update before we disclose the
vulnerability publicly.


Private security update channel
-------------------------------

We use a private channel to notify a small group of trusted Fedify users about
security updates before the embargo ends so they can take protective measures.
To request access, contact a Fedify maintainer privately and show that you have
at least one service or project that uses Fedify.
